# NovaSprite

> An AI sprite generation tool, built for the people who build worlds.

NovaSprite is an AI sprite generation tool for game developers. Frame-aligned sheets, true alpha, locked style — ready for Unity, Godot, and Unreal.

[**novasprite.tech**](https://novasprite.tech) — &nbsp;[**@novasprite_**](https://x.com/novasprite_)

---

## Philosophy

A sprite tool earns its place in your pipeline three ways.

**01 — Style locked across frames.** Same silhouette, same palette, same lighting — frame after frame. No drift, no re-rolls, no reconciliation work.

**02 — Alpha edges that ship.** Transparent backgrounds with clean edges. No halos, no fringe, no manual masking before import.

**03 — Output engines accept.** Sheets aligned to your grid, named by your convention, exported in the format your pipeline already speaks.

Everything else is wallpaper.

---

## Engines

| Engine | Format |
|---|---|
| Unity | `.png` + `.meta` |
| Godot | Texture2D regions |
| Unreal | Paper2D flipbook |
| Web | PNG + JSON atlas |
